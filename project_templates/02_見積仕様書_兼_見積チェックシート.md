## 3. 受託開発案件 見積書作成チェックシート（11項目）（Ⅲ-1.5）

| No. | チェック項目 | 確認のポイント | 確認結果（済／未／対象外） | リスク・備考 |
| :---: | :--- | :--- | :---: | :--- |
| **①** | **提案の範囲と要件** | 見積範囲と「範囲外」が明記されているか。未確定事項が洗い出されているか。 | | |
| **②** | **利用技術・開発手法** | 未経験技術や新製品の有無。プロトタイプ検証や技術習得工数を見込んだか。 | | |
| **③** | **要求性能（非機能要件）** | レスポンス、スループット、可用性（SLA/SLO）等の非機能要件と検証工数を見込んだか。 | | |
| **④** | **HW・SW・NW構成** | インフラ・ミドルウェア構成、他ベンダ担当領域との境界・制約を確認したか。 | | |
| **⑤** | **大日程計画と要員・教育計画** | クリティカルパス、要員調達リードタイム、不足スキルの教育期間・コストを含めたか。 | | |
| **⑥** | **開発量と生産性の見積** | 複数技法（類推/FP法とボトムアップ）でクロスチェックし、乖離を検証したか。 | | |
| **⑦** | **共同提案・マルチベンダ** | 他社との責任分界点（RACI）とインタフェース調整工数を見込んだか。 | | |
| **⑧** | **責任範囲とリスクの明確化** | 顧客の役割・免責事項を明記し、識別リスクに対するプロジェクト予備費を計上したか。 | | |
| **⑨** | **開発の採算性** | PMが算出した開発原価見積を営業値引きと混同して不当に圧縮していないか。 | | |
| **⑩** | **開発設備・テスト環境** | 開発端末、複数テスト環境、本番同等環境、テストデータ準備の費用と期間を見込んだか。 | | |
| **⑪** | **特許・関連法規・OSS** | 第三者特許、下請法、派遣法、個人情報保護、OSSライセンス（GPL等）を確認したか。 | | |
